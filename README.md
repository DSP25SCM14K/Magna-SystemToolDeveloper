# Magna System Tool Developer Portfolio

Dev Kumar's systems and tooling engineering portfolio, built from the experience and projects in the Magna System Tool Developer résumé.

## Highlights

- Animated professional headline and responsive systems-inspired visual design
- Complete work history with every résumé bullet
- Sensor-data workflow diagram from capture through validation
- 16 project cards with source links and demos where available
- IEEE publication, certificate, education, GitHub, and LeetCode links
- Automated GitHub Pages deployment

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
GITHUB_ACTIONS=true npm run build:pages
```

The GitHub Pages workflow publishes the static export whenever `main` is updated.
